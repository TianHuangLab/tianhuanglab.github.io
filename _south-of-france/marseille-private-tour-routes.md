很多人把马赛（Marseille）当作南法第一站，是因为这里有机场、有 TGV 火车站，也有真正属于地中海的生活气息，是地中海沿岸最大的城市之一。老港、守护圣母大教堂、卡西斯（Cassis）、普罗旺斯小镇、阿维尼翁（Avignon）、尼斯（Nice）方向，其实都可以从马赛出发慢慢游览。

但马赛出发怎么玩，不能只看“附近有什么景点”。你要先看看自己计划游览几天，住在哪里，同行人大概是什么情况，有没有老人孩子，最后是返回马赛离开，还是一路玩到尼斯再离开。总之，不同的情况可以优化出不同的行程线路。

我常驻马赛，平时接机、带团、做路线，大部分南法行程也都是从这里开始或在这里收尾。我的思路很简单：**马赛很适合作为南法包车路线的起点，但不适合把所有方向的行程都硬塞进一天。**

## 1. 马赛适合作为南法出发地吗？

适合，而且很适合！

马赛有两个优势。第一，它是南法真正的大城市，航班、火车、酒店、餐厅和港口都比较完整。第二，它的位置很方便：往西北可以去阿维尼翁、阿尔勒（Arles）和普罗旺斯小镇，往东可以去卡西斯、戛纳（Cannes）、昂蒂布（Antibes）、尼斯、埃兹（Èze）和摩纳哥（Monaco）。

也就是说，你可以把马赛当作一趟南法旅行的开场。

但我需要提醒的地方是：马赛不是那种“可以连续住一周，所有地方都轻松当天往返”的城市。它更适合做出发点，或者做前两到三晚的基地。想要把普罗旺斯和蔚蓝海岸都玩得舒服，后面通常还是要看情况换到阿维尼翁、艾克斯普罗旺斯（Aix-en-Provence）或尼斯附近住。

## 2. 只有1天：马赛老港 + 守护圣母 + 卡西斯

如果你只在马赛停留一天，我会建议别贪多。

这一天最经典，也最不容易出错的路线是：

**马赛老港 → 守护圣母大教堂 → 卡西斯小镇 → 卡朗格峡湾海景 / 游船 → 返回马赛**

马赛老港是这座城市的起点。早上在老港附近走一走，看渔船、市集、咖啡馆和港口光线，会比直接冲景点舒服很多。守护圣母大教堂在山上，是看马赛全景最好的地方之一。到了那里，你会一下子明白马赛为什么不是普通的法国城市，它更粗粝，也更有海港的生命力。

下午可以去卡西斯。这个小镇离马赛不远，但气质完全不一样。小港口、彩色房子、海边餐厅、卡朗格峡湾，适合给马赛的一日游一个很漂亮的收尾。

**适合谁？**  
适合邮轮停靠、马赛机场或火车站进出、只住马赛一晚、或者想先轻松感受地中海的人。

**公共交通可以吗？**  
可以，但卡西斯火车站离小镇中心还有一段距离，旺季接驳和打车不一定舒服。带行李、带老人孩子，或者时间很紧，包车会省事很多。

## 3. 有2天：一天马赛海岸，一天普罗旺斯小镇

如果你有两天，我会更推荐这样分：

| 天数 | 推荐安排 | 适合的感觉 |
|---|---|---|
| D1 | 马赛老港、守护圣母、卡西斯 | 先进入地中海海港和峡湾的感觉 |
| D2 | 石头城 Gordes、泉水小镇 Fontaine-de-Vaucluse、红土城 Roussillon / 塞南克修道院 | 把时间留给普罗旺斯的小镇、石墙、泉水和乡间光线 |

这两天的好处是层次很清楚：第一天看海，第二天进普罗旺斯腹地。

我自己带客人走这条线时，通常不会把第二天排得特别满。石头城很适合早一点到，阳光还没有太硬，小镇也没有完全被旅行团填满。泉水小镇更适合慢慢走一段，坐下来喝点东西。红土城很好看，但夏天会晒，带老人孩子时要看体力。

如果是薰衣草季，第二天可以根据花况加塞南克修道院；如果不是花季，就别执着于“必须看花”，普罗旺斯的小镇本身就很好看。

## 4. 有4天：马赛、普罗旺斯、尼斯方向都能放进来

4天是我觉得很舒服的一个南法行程长度，刚好兼顾普罗旺斯+蔚蓝海岸。

它比一日游从容很多，又不像7天那样需要完整假期。第一次来南法，想从马赛出发，同时看普罗旺斯和蔚蓝海岸，4天可以这样安排：

| 天数 | 路线 | 建议 |
|---|---|---|
| D1 | 马赛接机/接站，老港，守护圣母，卡西斯 | 先适应，不要第一天排太重 |
| D2 | 普罗旺斯三小镇 | 石头城、泉水小镇、红土城或塞南克修道院 |
| D3 | 马赛出发，戛纳，昂蒂布，尼斯 | 一路向东，不要回马赛更轻松 |
| D4 | 尼斯，埃兹，摩纳哥，尼斯或马赛送机 | 看航班决定从尼斯结束，还是回马赛 |

这条线最适合家庭、情侣和朋友小团。因为它不是单纯“多看几个点”，而是把南法的三种气质放进来：马赛的海港、普罗旺斯的小镇、蔚蓝海岸的海景。

如果你的航班允许，我更喜欢马赛进、尼斯出。这样不用回头。如果必须马赛往返，也能安排，只是最后一天车程会更长，路线要留一点余地。

## 5. 有7天：从马赛打开完整南法

如果你有7天，马赛出发就可以做一条比较完整的南法路线。

我的推荐方向是：

**马赛 → 卡西斯 → 普罗旺斯三小镇 → 阿维尼翁 / 阿尔勒 → 艾克斯普罗旺斯 → 尼斯 → 埃兹 → 摩纳哥 → 戛纳 / 昂蒂布**

7天的好处，是不用把每天都排得很满。你可以在马赛和卡西斯留一点海边时间，在普罗旺斯小镇慢一点，也可以在尼斯连住，拿一天去埃兹和摩纳哥，另一天去昂蒂布和戛纳。

如果你带父母孩子，我会更建议减少换酒店次数。比如前半段住马赛或阿维尼翁附近，后半段住尼斯。这样行李不会每天都搬，人的状态也会好很多。

7天也比较适合把“主题”放进来。喜欢艺术，可以加阿尔勒和圣保罗德旺斯；喜欢古罗马，可以加尼姆（Nîmes）和阿尔勒；喜欢海岸，可以多留一天给尼斯和周边。

## 6. 马赛包车和公共交通怎么选？

如果只是马赛市内玩，公共交通和步行就够了。

如果从马赛去卡西斯，公共交通也能做到，只是接驳不一定舒服。去普罗旺斯小镇、塞南克修道院、红土城、圣十字湖（Lac de Sainte-Croix）这些地方，公共交通就会明显消耗你的游览时间。

我会这样总结：

| 你的情况 | 更适合 |
|---|---|
| 两个人，轻装，只玩马赛市区 | 步行、地铁、公交 |
| 两个人，去卡西斯一日 | 公共交通或包车都可以 |
| 3到6人家庭或朋友小团 | 更建议认真考虑包车 |
| 带老人孩子、行李多 | 包车会舒服很多 |
| 想一天看普罗旺斯三小镇 | 包车更实际 |
| 想从马赛一路玩到尼斯 | 多日包车或定制路线更合适 |

我不会说所有人都该包车。南法不是这样玩的。

如果你喜欢自己做攻略，同行人也愿意配合，公共交通和自驾都很好。但如果你难得来一次，带着家人，想把时间留给海边、小镇和旅行本身，包车的价值就不只是“有一辆车”。

## 7. 从马赛出发，常见的几个误区

**误区一：马赛附近都可以轻松当天往返。**  
不是。卡西斯、艾克斯比较轻松；普罗旺斯三小镇可以当天往返，但需要安排好时间；尼斯、摩纳哥方向更适合一路玩过去。

**误区二：马赛不值得停留。**  
我不太同意。马赛不是精致小城，它有自己的粗粝和生命力。老港、守护圣母、海岸线、移民文化和餐桌上的地中海味道，都很有辨识度。

**误区三：包车就是为了看更多景点。**  
其实不是。包车更重要的是减少折腾，让路线更适合同行人的状态。尤其是家庭旅行，一天少一点疲惫，体验会差很多。

**误区四：所有南法路线都应该从尼斯开始。**  
尼斯很适合玩蔚蓝海岸，但如果你想看普罗旺斯和马赛，马赛出发反而更自然。

## 8. 如果你住在马赛，我会先问这几个问题

在真正安排路线前，我通常会先看这些：

- 你是马赛机场到达，还是马赛圣夏尔火车站到达？
- 在马赛住几晚？
- 最后从马赛走，还是从尼斯走？
- 同行几个人，有没有老人孩子？
- 更想看海，还是更想看普罗旺斯小镇？
- 能不能接受换一次酒店？
- 有没有已经订好的门票、餐厅或酒店？

这些问题听起来很细，但它们会直接决定行程路线怎么安排。

如果你只说“我想玩南法”，答案会很大；但如果你说“我们一家三口，马赛进出，住三晚，想看卡西斯和小镇，不想太累”，路线马上就清楚很多。欢迎找我聊聊～
