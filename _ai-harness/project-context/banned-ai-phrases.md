# Banned / Cautious AI Phrases

这个文件记录奥利旅行内容中需要避免或谨慎使用的 AI 味表达。

这些词不是绝对不能出现，但如果没有非常自然的语境，默认不要用。

## 尽量避免

- 先这么选
- 先给你一个判断
- 这样走最顺
- 不杀行程
- 避坑指南
- 一文看懂
- 保姆级攻略
- 必打卡
- 宝藏小镇
- 松弛感拉满
- 打卡
- 解锁
- 沉浸式
- 绝美
- 史上最全
- 直接抄作业
- 高效玩转
- 轻松搞定
- 省心省力
- 不走回头路
- 深度体验风土人情
- 旅行小白必看
- 纯干货
- 超详细
- 码住

## 替代表达

| 不建议 | 更自然 |
|---|---|
| 先给你一个判断 | 我会先把结论说在前面 |
| 先这么选 | 如果你是这种情况，可以考虑这样安排 |
| 这样走最顺 | 这样安排，路上会少折腾一点 |
| 不杀行程 | 不会把一天排得太满 |
| 避坑 | 有些地方听起来不错，但实际要看情况 |
| 必打卡 | 如果时间不多，我会优先留给这里 |
| 绝美 | 很好看 / 很有味道 / 这个角度确实值得停 |
| 深度体验 | 多留一点时间，才比较容易感受到它的味道 |
| 保姆级 | 我尽量把你真正会遇到的问题说清楚 |
| 纯干货 | 直接说对你有用的部分 |

## 检查规则

每次生成文章后，搜索这些表达。

如果出现，必须判断：

1. 是否真的符合作者语气；
2. 是否有更自然的替代表达；
3. 是否会让文章像普通 AI 攻略；
4. 是否损害个人品牌的真实感。

默认原则：

> 能不用就不用，能换成人话就换成人话。
