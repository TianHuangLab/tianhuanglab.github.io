## ✨行程亮点

**这是一条为首次探访南法量身打造的 4 天 3 夜诗意画卷：从马赛与卡西斯的湛蓝海风启程，徐徐漫入普罗旺斯的油画山城，再顺着蔚蓝海岸延伸至戛纳、昂蒂布、尼斯、埃兹与摩纳哥。**

若觉得 1 天过于匆忙，7 天又难以凑出假期，这条 4 天 3 夜便是落得恰到好处的温柔折中。它不贪求将南法全景强行塞满，而是精心选粹了地中海最耀眼的几重意象：古老海港、峭壁峡湾、金色小镇、云端山城、艺术海岸与摩纳哥的微奢夜色。

第一天在马赛拉开序幕。老港的船樯晨光、守护圣母大教堂顶的俯览，以及卡西斯的断崖海浪，会用最直接的方式将你拉入地中海的慢悠节奏。第二天全心交给普罗旺斯腹地：千年的石头城、清泉流淌的泉水小镇、红土斑斓的红土城，夏季还能撞见塞南克修道院前那一抹迷人的紫草花海。第三天沿着蔚蓝海岸向东穿行，在戛纳走过影展红毯，去昂蒂布感受毕加索偏爱的清透日光，最终在尼斯的阳光下定格。第四天前往悬崖之巅的中世纪仙境埃兹与摩纳哥，行程可以在尼斯优雅落幕，亦可专车顺畅返抵马赛。

这条路线尤其适合家庭度假、情侣漫游与闺蜜小团。你无需把精力耗费在研究班次、山路驾驶和繁琐停车上；具体的车程安排与节奏调配交给我们，你只需负责将时光毫无保留地浪费给南法的阳光、海风与微醺小镇。

## 行程详情

这条南法4天3夜路线，推荐从 **马赛普罗旺斯机场（MRS）** 或 **马赛圣夏尔火车站（Marseille Saint-Charles）** 抵达，从 **尼斯蓝色海岸机场（NCE）** 离开。这样可以一路从马赛走向蔚蓝海岸，减少折返。当然你可以从尼斯开始行程，最后在马赛结束。

如果你的航班已经定在马赛往返，也可以把第四天调整为尼斯、埃兹、摩纳哥之后返回马赛。是否适合当天返回，要看航班时间和同行人的体力。

### 第一天｜马赛接机/接站 → 马赛老港 → 守护圣母大教堂 → 卡西斯小镇

**关键词：马赛抵达、老港、守护圣母大教堂、马赛全景、卡西斯、南法海风、峡湾印象**

抵达马赛后，先安排接机或接站，前往酒店放下行李。首日行程提倡轻便舒缓，协助你快速进入南法惬意节奏。

首先登顶马赛至高点**守护圣母大教堂**。站在大教堂的俯瞰台，将马赛古城、老港全景以及远处的地中海海岸线尽收眼底。随后漫步至马赛的人文核心**马赛老港**。这里穿梭着归航的渔船与沿街咖啡馆，洋溢着最地道的地中海生活气息与市井烟火。

如果抵达时间较早，我们会在午后前往卡西斯小镇。彩色港口、海边餐厅和卡朗格峡湾的蓝色，会给这趟旅行一个很漂亮的开场。如果时间较晚，则建议留在马赛老港享受海鲜晚餐和落日，把卡西斯小镇顺延至后续行程中。

### 第二天｜普罗旺斯三小镇一日：石头城 → 泉水小镇 → 红土城 / 塞南克修道院

**关键词：Gordes、Fontaine-de-Vaucluse、Roussillon、塞南克修道院、普罗旺斯小镇**

这一天留给普罗旺斯腹地。清晨驱车前往悬崖之上的**石头城**。先在经典观景台留影，再走进这个迷人的中世纪古村落。

石头城是普罗旺斯最有代表性的山城之一，远看很美，走进村里又是另一种石墙、巷道和山谷的气质。随后抵达**泉水小镇**，沿着绿树成荫的清冽溪流漫步，在河畔餐馆享用午餐，享受山谷间独特的清凉与宁静。

下午可以前往**红土城**，漫步南法少有的赭红色山丘小镇，打卡暖色调建筑与赭石步道，感受鲜艳浓郁的自然色彩。如果是薰衣草季，我们也会把塞南克修道院加入当天行程安排。

### 第三天｜马赛 → 戛纳 → 昂蒂布 → 尼斯

**关键词：蔚蓝海岸、戛纳、昂蒂布、尼斯**

今天从马赛一路向东，正式进入蔚蓝海岸。

首站抵达**戛纳**，打卡著名的影节宫与星光红毯，漫步充满法式度假风情的克鲁瓦塞特海滨大道。随后顺海岸线前往**昂蒂布**。这座海滨小镇兼具奢华游艇码头与古老城墙的烟火气。漫步古城巷道，参观坐落于海边古堡内的毕加索博物馆，感受艺术与地中海海风的碰撞。

傍晚抵达**尼斯**。今晚无需赶路折返，可在尼斯老城区享用地道南法晚餐，随后来到著名的英国人散步大道，在落日与海浪声中完成从普罗旺斯小镇到海滨度假的完美过渡！

### 第四天｜尼斯 → 埃兹 → 摩纳哥 → 尼斯或返回马赛送机/送站

**关键词：尼斯、埃兹、摩纳哥、悬崖小镇、地中海全景**

最后一天从尼斯出发，先前往**埃兹**悬崖小镇。这个山顶小镇是蔚蓝海岸最有代表性的地点之一，穿过古老的石头巷道，登顶著名的山顶热带花园，在至高点定格地中海最壮丽的绝壁海景。

随后顺山路进入**摩纳哥**，漫步亲王宫广场，俯瞰游艇云集的摩纳哥港，随后前往蒙特卡洛赌场，近距离感受经典赛道与奢华建筑的风采。

如果从尼斯机场返程，第四天会比较从容，游览结束后直接专车送机/送站；如果需要返回马赛送机或送站，也可以安排，但建议选择较晚航班，或在马赛多住一晚，确保收尾行程从容不赶。

      images.forEach(file => {
        const img = document.createElement("img");
        img.src = `/assets/img/${folder ? folder + "/" : ""}${file}`;
        img.alt = file.replace(/_/g, " ").replace(/\.(webp|jpg|jpeg|png)$/i, "");
        img.loading = "lazy";
        img.onerror = () => console.warn("图片加载失败:", img.src);
        container.appendChild(img);
      });
    });
  }

  document.addEventListener("DOMContentLoaded", loadLocalImages);
</script>

## 行程说明

- **行程安排：** 本产品一共4天3晚，推荐马赛进、尼斯出；亦可根据你的机票/车票灵活调整为尼斯进、马赛出或马赛/尼斯同城往返。
- **用车方式：** 本线路以5座车或8-9座商务车小团包车为主。部分老城、山顶小镇和海岸景点会根据当地交通规则安排步行或定点上下车。
- **酒店选择：** 常见安排为马赛或普罗旺斯周边2晚，尼斯1晚；也可根据航班、预算和同行人情况调整住宿城市。
- **行程强度：** 4天3夜行程强度适中。如果带老人孩子，可以减少部分小镇步行或缩短盘山车程，确保全家出行轻松舒适。
- **接送安排：** 可根据最终方案安排马赛、尼斯机场或者周边城市如阿维尼翁、艾克斯等主要机场或火车站接送。常见交通枢纽包括：
    - 马赛圣夏尔火车站（Marseille Saint-Charles）
    - 马赛普罗旺斯机场（Marseille Provence Airport，机场代码 MRS）
    - 尼斯蓝色海岸机场（Nice Côte d’Azur Airport，机场代码 NCE）

*具体接送范围、是否包含在报价内，以及跨境段采用何种交通方式，会在正式报价时与你确认。全程可提供中文、英文、法语沟通支持，让长线旅行中的每一次衔接都更清楚、更安心。*

## 注意事项


{% details 安全须知 %}
为了保障您的行程体验与出行安全，请您务必仔细阅读以下提示：

**上车与行程安排**

- 请您提前到达约定集合地点，避免因交通、退房、行李整理或临时情况影响当天行程。
- 本路线涉及城市较多，所有出发和抵达时间均为参考时间，可能因天气、交通、罢工、封路、边境检查、火车延误等原因调整。
- 行程顺序与停留时间会根据当日实际情况灵活调整，以最终确认和现场安排为准。

**乘车与游览安全**

- 车辆完全停稳后方可上下车，乘车途中请勿将头手伸出窗外，不催促司机超速行驶。
- 城市景区、南法山顶小镇等区域可能存在台阶、坡道或湿滑路面，请穿着舒适防滑的鞋。
- 游览、用餐、购物和自由活动时，请妥善保管护照、钱包、手机和贵重物品。

**酒店入住安全**

- 入住酒店后请确认门窗锁好，贵重物品建议随身携带或存放至酒店保险柜。
- 离店前请检查护照、充电器、银行卡、药品和儿童用品等重要物品。
- 遇火警或突发事件，请遵守酒店指引，从安全通道有序撤离。

**饮食与健康提示**

- 旅行中城市和国家切换较多，建议合理安排饮食和休息，不要每天都排得过满。
- 南法夏季早中晚温差较大，请根据季节准备外套、防晒、雨具和常用药品。
- 若自愿参与滑雪、登山、游船、潜水、帆船等项目，请根据个人身体状况谨慎选择，并自行承担相关风险。

**自由活动与个人安全**

- 自由活动期间建议结伴同行，避免夜间单独前往偏僻区域。
- 如需临时离队或自行前往其他地点，请提前告知并保持通讯畅通。
- 携带未成年人的游客，请全程履行监护责任，尤其注意车站、机场、湖边、山地和人流密集区域。

**购物与财务安全**

- 马赛、尼斯等热门旅游城市需特别注意防盗抢，尤其是在火车站、地铁、景点周边和购物区。
- 购物时请保留收据、退税单和发票，贵重商品请确认退换、保修和海关携带规则。
- 请勿轻信街头陌生人搭讪、低价换汇、流动商贩或来路不明的购物推荐。

**其他重要说明**

- 暑期、圣诞新年、滑雪季、展会和当地节庆期间，酒店、交通和服务价格可能明显上涨，请尽早咨询确认。
- 如遇不可抗力或供应方临时调整，行程可能需要替换景点、调整顺序或更改交通方式，敬请理解。
- 建议购买覆盖欧洲旅行的旅游保险，尤其关注医疗、行李、航班延误、交通中断和个人财物保障。
